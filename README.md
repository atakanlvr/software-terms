# Yazılım Terim Defteri

Yazılım temellerini terim terim öğrenmek için çalışma uygulaması: tek cümlelik tanım, pseudo code akışı ve işaretlemeli test.

## Yayına alma (GitHub Pages)
1. Bu klasördeki dosyaları public bir repo'nun köküne yükle.
2. Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)` → Save.
3. 1-2 dakika sonra `https://<kullanıcı-adı>.github.io/<repo-adı>/` adresinde yayında olur.

## iPad'e kurma
Safari'de adresi aç → Paylaş → Ana Ekrana Ekle. Uygulama tam ekran açılır, ilk açılıştan sonra internetsiz de çalışır.
