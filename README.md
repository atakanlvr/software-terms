# Yazılım Terim Defteri

Yazılım dünyasında her gün geçen 168 terimi 15 modülde öğrenmek için çalışma uygulaması. Her terimde tek cümlelik tanım, akılda kalsın notu, pseudo code ile akış ve 3 soruluk işaretlemeli test var.

## Dosyalar
- `index.html`: uygulamanın kendisi
- `terms.js`: tüm modüller ve terimler (içerik)
- `sw.js`, `manifest.webmanifest`, ikonlar: iPad'de uygulama gibi ve internetsiz çalışması için

## iPad'e kurma
Safari'de `https://atakanlvr.github.io/software-terms/` adresini aç → Paylaş → Ana Ekrana Ekle.
